# Security policy

This project contains command policy and sandbox integration code. Please do
not publish an unpatched bypass before maintainers have had a reasonable chance
to investigate it.

Until a private reporting address is published, use GitHub's private security
advisory flow for this repository. Include the pinned component version,
platform, DSH profile, minimal policy/configuration, command, expected behavior,
and observed behavior.

Only releases explicitly listed as supported receive security fixes. The
current repository is pre-release and does not yet advertise a supported
release.
